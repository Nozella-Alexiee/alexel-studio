How it works

From prompt to commit, you stay in charge.

  1. Claude Code, Codex, Gemini, Antigravity or any ACP agent. Switch any time from the panel header.

  2. Mention files with @, or add @problems and @terminal for context. The agent reads your project and plans the change.

  3. Every edit and command waits for you as a card with the exact diff. Allow once, for the session, or say no.

  4. Changed parts light up right in the editor. Keep one, revert another, then carry on typing.

  5. Every message is a checkpoint. One click puts your files back the way they were before it.

  6. Set a breakpoint, press F5, and step through line by line with variables and the call stack.

Approvals

See the diff before anything changes.

  • Edits and shell commands show up as a card with the exact diff or command.
  • Allow once, allow for the session, or decline and tell the agent what to do instead.
  • Choose the model, effort and permission mode for each conversation.
  • Pick up any earlier conversation from history.
Debugger

Breakpoints, variables, call stack.

Press F5 on a JavaScript, TypeScript, Python, C, C++ or Go file. Alexel Studio reads your .vscode/launch.json, or builds a configuration for you.

  • Hover a variable to see its value while paused.
  • Evaluate expressions in the Debug Console.

Questions

Is it really free?

Yes. Alexel Studio is open source under the MIT license. There is no account, no paid tier and no telemetry.

Do I need an AI subscription?

Only for the agent you want to use. Each agent signs in with its own account: Claude Pro or Max for Claude Code, ChatGPT or an OpenAI API key for Codex, a Google account or Gemini API key for Gemini. The editor, terminal and debugger work without any of them.

Can an agent change files without asking?

Not in the default mode. In Ask first, every edit and shell command waits for your approval. You can switch a conversation to automatic edits or plan only, and every save stays in file history.

Do VS Code extensions work?

Color themes, file icon themes, snippets and language grammars from Open VSX work. The Claude Code and Codex extensions install as agents. Extensions that run their own code, such as GitLens, are not supported.

What do I need to run it?

macOS 12 or later (Apple Silicon or Intel), Windows 10 or 11 (x64 or ARM64), or 64-bit Linux with glibc 2.31 or later, and about 500 MB of memory.
